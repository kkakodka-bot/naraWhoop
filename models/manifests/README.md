Each JSON pins a full 40-character source commit. External source pins were checked using upstream Git references on 2026-09-18; the local softmax source is pinned to its unchanged original implementation commit. wav2sleep's code/checkpoint revisions also match the supplied specification. License evidence links target the pinned revision; “declared_upstream” records a source declaration, including the local repository's declaration, not a legal approval. Code, weights and training-data licenses have separate fields and statuses. An absent checkpoint is null, never a fabricated hash. Inspect actual checkpoint bytes before replacing nulls.

`preprocessing_source` identifies a repository-relative Python source file; `preprocessing_sha256` is SHA-256 of that file's exact bytes, not of the descriptive `input_contract` object. The file includes the candidate's implemented preprocessing or its wrapper around the pinned upstream preprocessing. The runtime-wide `adapter_sha256` and `implementation.implementation_sha256` additionally bind all runtime Python files and `upstream-lock.json` through `physiology_inference.contracts.implementation_hash()`. These hashes bind implementation bytes, not physiological qualification or permission to execute. Inference tests verify all eight inventories against the current source.

Executable shadow candidates must supply immutable preprocessing/quality/adapter hashes, checkpoint hash where applicable, separately reviewed applicable rights, evaluation dataset rights, bounded threads/concurrency, timeout, RSS limit and reproducibility tolerance. The adapter must own an exact-version environment lock and prove matching training/inference preprocessing; these metadata files do not install or execute anything. Actual-VPS resource measurements and hardware soak are additional promotion gates, not inferred from configured server size.

Keep operational status, reference-validation status and publication authorization distinct. Do not change `metadata_only` merely because a wrapper imports successfully; missing raw channels, timing, continuity, preprocessing or rights must still prevent invocation. Adult/pediatric, device/site, sensor-placement and firmware claims require explicit supported-cohort evidence.
