# Optional model evaluation gates

No model is activated, promoted or downloaded in this change. The current checked-in manifests are shadow candidates with `canonical_outputs_allowed: false`. Their historical synthetic execution notes are inherited repository records, not fresh target-device or VPS measurements. The deterministic window/reason path must continue when assets are absent, qualification rejects input, a worker crashes or a model times out.

Exact weight/config and code/preprocess/quality hashes remain in [`models/manifests`](../../models/manifests/). Revalidate the actual files and applicable rights before any authorized evaluation; a URL or hash in metadata is not proof the approved asset is installed.

`VerifiedModelJobAssembler` currently accepts only wav2sleep and NeuroKit2, one identified optical channel, at most 8 raw objects, at most 14 hours, 1.3 million samples and 15 MiB serialized input. It binds owner/device/revision, checkpoint, preprocessing, quality policy and reviewed capture metadata. NPB1 structure/digest validation alone does not pass acquisition qualification. Preserve these limits until representative measured streaming/chunking evidence supports a specific revision.

The Python runtime has a single admission slot, explicit thread bounds, finite input/output limits, child deadlines and isolated credentials. Candidate manifest resource fields that remain null must be filled by measurement and policy before activation. Test absent model, failed import, corrupt asset, wrong tensor/channel, gap, timeout, memory pressure, stale revision and another user's queued work while verifying deterministic publication independently.

A reproducible comparison pins code, asset bytes, environment lock, preprocessing, channel/rate/units/clock mapping, acquisition evidence, quality policy, split manifest and reference labels. It emits modality/duration, causal or retrospective mode, coverage/reasons, participant-level error/uncertainty and CPU/RSS/latency. Selection requires a frozen held-out policy and reviewed rights; it never writes activation/source-selection state automatically.
