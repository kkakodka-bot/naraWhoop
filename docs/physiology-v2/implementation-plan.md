## Sequence and shared contracts

W0 acquisition and W1 durable server prerequisites precede W2/W3 integration. W2 and W3 may then proceed against versioned contracts; W4 waveform paths require verified input and remain shadow. W5 implements evaluation and promotion controls, with accuracy promotion blocked until external evidence exists.

Native migrations retain v46 RR source and v47 legacy cache. v48 repairs PPG identity; v49 adds owner-scoped physiology cache; v50 adds checked RR receipts. Android Room39->40 repairs PPG, and40->41 adds receipts. Shared schema/decoder/transport oracles stay synchronized.

Server ownership is `(user_id, device_id, period, algorithm_version, input_revision)`. Work claims include random lease token, run ID, claimed revision, expiry and historical IANA timezone. Publication must lock and validate the work row in the same transaction that replaces generated results. A newer input revision invalidates publication. Success counts are independent of the per-revision failure budget. Manual overrides/tombstones retain their own ownership.

One canonical result DTO supplies SQL publication and immutable archive payloads. It carries source/device, revision, algorithm/model/preprocess/quality versions, event-time coverage, observed-through/computed times, causal/retrospective mode, promoted/shadow state, and separate archive verification state. Sleep has four stages plus unknown, with qualified binary `sleep_unstaged` separate from `state_unknown`. HRV uses original beat identities and explicit eligible-pair masks; observed and corrected values remain separate. Five-minute windows are half-open UTC multiples of 300 seconds. Unsupported timing never becomes invented subsecond precision.
