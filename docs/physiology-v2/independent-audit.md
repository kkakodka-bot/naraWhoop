**ACQ-1 — P0.** Requirement: W0 durable acquisition/replay and ACK only after successful storage. Evidence: `Store/StreamStore.swift:312-323` applies `maxTs <= frontier` suppression to twelve streams; `Strand/Collect/Backfiller.swift:886,1042` proceeds through insertion to ACK without a storage failure. Impact: absent older samples can be lost before history ACK, particularly when optional raw capture is absent. Regression: `BackfillFrontierTests` covers all twelve streams, late/equal-second data and stable replay. Evidence: `A/acquisition/late_backfill.swift`, `A/repairs/acquisition/repair-results.md`.

**ACQ-2 — P1.** Requirement: W0 raw object export must preserve verified bytes on both platforms.
