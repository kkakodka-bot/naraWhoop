## Remaining acceptance blockers

These are open **external P1 acceptance gates**, not claims that repaired source defects remain:

| Gate | Exact missing evidence | Consequence |
|---|---|---|
| Scientific qualification | Target-device synchronized adjudicated ECG, PSG/opportunities and respiratory references; prospective frozen policy; person-held-out accuracy/coverage/subgroup results | HRV, sleep and respiration stay shadow |
| Device/acquisition qualification | Reviewed beat/waveform timing and channel contracts on actual hardware; final-build overnight locked-phone continuity/coverage evidence | Unsupported inputs remain unavailable/unknown |
| Deployment qualification | Reviewed immutable Linux environment/checkpoint package and actual-VPS resource/concurrency/headroom measurements | Candidate code is not a deployment approval; packaging attempts/results are recorded separately in the final ledger |
| Canonical promotion | Real independent reviewer approvals bound to the final immutable feature manifests and reference evaluation | No automatic canonical replacement; retained legacy remains selected |

- Reference validation is **NOT_READY** for all three features: no target-device synchronized ECG/PSG/respiratory-reference cohort, adjudication package, held-out participant report or frozen prospective acceptance policy has been supplied. See `reference-validation-production-candidate.md`.
- Acquisition readiness remains feature/input-specific. A scalar timestamp or a raw count array is not verified beat timing, optical semantics, synchronized waveform coverage or respiratory ground truth. Unsupported model inputs must remain unknown/unavailable.
- Device continuity and overnight soak must be demonstrated on the final iPhone build. Simulator/source tests do not establish protected-data, disconnect/reconnect, background acquisition or overnight completeness.
- Model/checkpoint licensing, frozen preprocessing/quality contracts, actual-VPS resource limits and deploy-time immutable images/configuration require their own reviewed evidence. A runnable synthetic/model smoke test does not authorize canonical use.
- Production approvals and deployments were not created by this audit. V2 stays shadow; each feature requires a separately reviewed signed approval. Rollback retains distinct algorithm identity.
