## Post-merge independent recheck

- The signed-promotion migration, model-queue migration and reference-validation tooling were unchanged by the upstream merge. Rechecked selection, snapshot identity, nested-feature filtering, durable activation/revision fences and shadow-only model readback retain their repaired boundaries.
- Explicit model activation/worker modes are parsed before ordinary scoring configuration. A broken optional model cannot stop the deterministic process at configuration loading. No-argument scoring remains persistent despite leftover replay environment variables; replay requires an explicit command.
- Read-only runtime preflight checks the new signed-promotion, model-queue and motion-provenance migrations/tables. It does not claim jobs, activate models or publish measurements.
- Respiratory work exceeding the bounded 512-window budget is distributed across the full eligible context, rather than taking an early-night prefix. Nightly coverage still uses the full context bounds, and an exactly full budget is not reported as truncated. The post-merge runner regression suite passed.
- Raw capture bounds are converted from inclusive seconds to a checked half-open manifest index without changing stored evidence or inferring continuous acquisition. This indexing repair does not qualify R-R timing or waveform channel semantics.
- Binary sleep has priority over disagreeing stage wake in Swift/Kotlin semantics and both server serialization paths. Historical orientation/dynamic-motion values remain stored but cannot become qualified v2 evidence without their corresponding acquisition provenance.
