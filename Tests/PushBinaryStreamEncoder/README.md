# Bounded binary encoder compatibility

Run the Swift package's focused tests:

```sh
swift test --package-path Packages/NoopPush --filter PushBinaryStreamEncoderTests
```

The 24 checked-in synthetic golden vectors cover all four NPB1 kinds, identity v1/v2,
gzip, and pinned Zstandard levels 1/3. Regenerate only for an intentional reviewed
codec change, then review the wire and decoded digests:

```sh
NOOP_STREAM_GOLDEN_OUTPUT="$PWD/Packages/NoopPush/Tests/NoopPushTests/Resources/streaming-npb1-golden.json" \
  swift test --package-path Packages/NoopPush --filter PushBinaryStreamEncoderTests
```

Verify the generated bytes with the actual receiver's independent codec and bounds
guard, using the repository's pinned Deno/cache environment:

```sh
deno run --cached-only --frozen --lock=supabase/functions/deno.lock --allow-read \
  Tests/PushBinaryStreamEncoder/verify.ts
```

`PushBinaryStreamEncoder.encode` accepts exactly one bounded selection through a
row iterator. It emits ≤64 KiB borrowed decoded slices into gzip or a single-threaded
Zstandard context, hashes both streams incrementally, and writes a protected temporary
file. It fsyncs the finished body, publishes an immutable digest-keyed hard link without
overwriting an existing object, verifies any existing body's size/digest, and fsyncs
the directory. Errors/cancellation remove the temporary file. A crash after publication
can leave a complete unreferenced body for conservative cleanup, never an authorized
receipt or source advancement. Account ownership/admission is supplied by the caller.

Memory includes the current source row and codec context. The codec does not make a
large source BLOB disappear; callers must bound source selection before loading BLOBs.
The default limits are 2,000 rows and 4 MiB decoded. `visitDecodedBytes` supports the
additional bounded hash passes needed by the existing stable batch/object UUID contract
after the decoded digest and then batch UUID become known. It does not reread the
backlog or alter saved legacy payload bytes. Fresh file-backed batch/journal integration
is a separate required gate; this primitive alone is not proof that every active path streams.

These tests measure local correctness and compatibility. Physical iOS RSS, energy,
thermal pressure, throughput, file-protection behavior while locked, and crash/power-loss
filesystem durability are `NOT_MEASURED` here.
